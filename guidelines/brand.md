# Brand Guidelines

## Brand Voice
- **Tone**: Sophisticated, minimal, timeless
- **Audience**: Modern consumers seeking quality essentials
- **Personality**: Curated, elevated, approachable luxury

## Logo Usage
- Primary logo: "E-Commerce Store" in Playfair Display, 900 weight, uppercase
- Tracking: 0.18em letter-spacing
- Always use primary text color on light backgrounds, white on dark

## Color Palette

| Token | Hex | Usage |
|-------|-----|-------|
| Primary | #1a1a1a | Headings, primary buttons, body text |
| Accent | #c5a059 | CTAs, prices, hover states, underlines |
| Accent Hover | #e0bc7a | Button/link hover states |
| Background | #ffffff | Main page background |
| Background Soft | #fcfcfc | Section alt backgrounds |
| Text Dark | #222222 | Body prose |
| Text Muted | #777777 | Secondary text, labels |
| Border | #eeeeee | Cards, dividers, inputs |
| Footer BG | #1a1a1a | Footer background |

## Theme Variants
- **Light** (default): Clean, high contrast
- **Dark**: Dark slate backgrounds (#0f172a), light text
- **Sepia**: Warm brown tones, paper-like feel
- **Ocean**: Cool blue tones, airy feel
